# AMC 8 Directory

Take a past AMC 8 as a quiz and see how you'd score.

| Year | Quiz |
| --- | --- |
| 2024 | [2024/index.html](2024/index.html) |

Each quiz has all 25 problems, including the figures, as multiple choice (A–E) like the real test. You answer one problem at a time, and each answer is graded right away with a short explanation of how to solve it. At the end you get your score out of 25 and can look back over every problem.

## Running a quiz

Open a year's `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 4280
```

Then go to http://localhost:4280/2024/.

Problems are from the AMC 8 competitions, © Mathematical Association of America.
